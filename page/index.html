Business Capabilities

Engineered for Transactional Reliability

Every operation strictly adheres to immutable models, inventory consistency, and historical price preservation.

Product Catalog

Full lifecycle management with unique names, fixed categories, COP unit pricing (Value Object Money), stock tracking, and image uploads up to 5 MB.

Atomic Point of Sale

Atomic transactions safeguarded by optimistic locking (version column with up to 3 automatic retries). Automatic stock deduction.

Consolidated Reports

High-efficiency aggregated reporting in database across date ranges, preserving historical product names at time of sale (DP-01).

Security & RBAC

Stateless JWT authentication with symmetric HS256 tokens and 30s clock leeway. Strict role hierarchy (Admin vs. Seller) enforcing DP-04.

Logical Deletion (Soft Delete)

Products are never physically erased if linked to commercial records. Soft Delete preserves referential integrity in MySQL.

Media & File Storage

Image persistence via shared named volume media_data with MIME validation, SHA-256 unique file naming, and Nginx proxy delivery.

Spec-Driven Development Methodology

Zero Assumptions. Total Spec Fidelity.

In SDD challenges, source code is the vehicle, not the ultimate goal. This implementation faithfully translated the abstract specification (conceptualized in Python and .NET) into the production stack: PHP 8.2 (Laravel 11) and React 18 without violating any of the 13 non-negotiable constitution articles or OpenAPI contracts.

Currency Invariant (H-2) Monetary figures represented with fixed decimal precision in COP with HALF_UP rounding.
Date Invariant (H-3) Ranges with exclusive upper bound (from <= sold_at < to) avoiding second loss.
Frozen Historical Names (DP-01) Reports and line items retain the product name at the time of sale even if renamed later.
No Default Secrets (Art. IX) Admin passwords and JWT keys are strictly supplied through environment variables in production.
